Foundation

Identity

Three elements: the primary lockup, the signifier and the bug. Every rule below is encoded as a token, so it cannot quietly be lost between the brand manual and production.

Primary lockup

One inline SVG serves both surfaces. The wordmark reads --inx-logo-word and the signifier reads --inx-logo-mark, and the ink surface re-points the first to white. I checked the two supplied files against each other before merging them: the dark version is a pure recolour at a different scale, with no optical correction to the letterforms (worst deviation 0.0003 of the lockup width), so collapsing them into one asset loses nothing. The separate static files are still in the handover for <img>, email and favicon use, where CSS variables don't reach.

Signifier & bug

A naming mismatch worth settling: the brand manual calls this element the symbol; the files from the branding department call it the signifier. The system uses "signifier" because that is what is written on the assets people will actually open, but the manual should be amended so one word wins. The bug is the signifier reversed out of an ink disc — the manual shows it, but no file was supplied, so it is composed here from the signifier at 46% of the disc diameter. Confirm that proportion against the original artwork.

Clear space

The flat ring is the mandatory clear space: one signifier height and width on every side. Measured from the artwork, the signifier is 74.78% of the lockup's height, so clear space is 0.748 × logo height — a ratio that holds at any size. At a 48px logo that is a 36px margin. This is --inx-logo-clear-ratio, applied by .inx-logo--clear.

Contrast rule from the manual: the ink lockup goes on light surfaces, the white lockup on dark. Where a background sits outside the palette, use the plain black or white version — never recolour the mark to match. The signifier stays Blue Slate on both surfaces; at 4.03:1 on Ink Black it would fail as text, but it is a graphic mark, not something anyone has to read.

Steps 950, 900, 500, 200, 50 and 0 are the approved colours. The rest sit on the straight line between them, which is what makes hover, border and disabled states possible without introducing an unapproved hue.

Usage proportion

Neutrals carry clarity, ink establishes authority, and the blues highlight without taking over. Blue Slate and Pale Sky together should stay under roughly a fifth of any composition.

Functional status colours Extension

Success Warning Error Info

The manual defines no status palette, but a form cannot report a validation error without one. These four are deliberately desaturated to sit beside the brand blues, and they are restricted to functional interface use — never in a marketing layout and never adjacent to the logo. Colour is always paired with a label or icon, so meaning never depends on hue alone.

Watch this one

Blue Slate cannot carry body text on dark

Blue Slate is the secondary text colour on light surfaces and fails as body text on dark ones. On ink, Pale Sky takes over for secondary text and Blue Slate drops back to borders, dividers and large display type. The .inx-on-ink class does this switch automatically — components need no dark variants of their own.

Focus ring

Section rhythm

Full-width page sections use space-10 (96px) vertical padding on desktop and space-8 (48px) below 900px. Blocks inside a section separate by space-8; elements inside a block by space-5. Keeping to three levels stops layouts drifting apart over time.

Tokens

Radius & elevation

Elevation is borders-first. The manual forbids effects on the identity and gradients in colour use, so depth here comes from line and surface rather than from glow.

radius-none · 0
Every corner in the system

radius-full · 50%
Spinner ring and radio only

Every corner is sharp. radius-sm, radius-md, radius-lg, radius-xl and radius-pill all resolve to 0 — buttons, cards, inputs, pills, tags and panels included. The named steps are kept so no component has to be rewritten and so a future direction can restore a scale in one place; nothing may reintroduce a corner radius locally.

radius-full is not a corner — it draws a circle, and it survives in exactly two places where the circle carries the meaning: the button loading spinner, which is a rotating ring, and the radio input, whose round shape is what separates it from a checkbox. It must never be used to round a rectangle.

Tokens

Motion

Calm and deliberate. Movement confirms an action happened; it does not perform.

TokenValueUse
--inx-duration-fast120msHover, colour change, press
--inx-duration-base200msMost transitions
--inx-duration-slow360msPanels, drawers, reveals
--inx-easecubic-bezier(0.2, 0, 0, 1)Default — decisive, settles quickly
--inx-ease-outcubic-bezier(0.16, 1, 0.3, 1)Entrances

No bounce, no elastic easing, nothing over 400ms. All durations collapse to 1ms under prefers-reduced-motion, which is handled in the token file so individual components never have to remember it.

Governance

Do & don't

The manual's misuse pages, translated into rules that apply to a screen.

Don't

Use gradients in colour application — flat fills only. See the note below on where the manual contradicts itself.

Don't

Set a headline in two colours. One text colour per block of copy.

Don't

Introduce a colour outside the palette or the derived ramp, including "just for this one badge".

Don't

Put the logo on a non-palette background. Use the plain black or white lockup instead.

Don't

Stretch, rotate, outline, recolour or add effects to the logo. Never rebuild the wordmark in Manrope.

Don't

Use Manrope Bold, Light or Medium. Regular and Semi Bold are the whole system.

Do

Keep generous clear space around every identity element — one symbol height on all sides.

Do

Let photography show real working moments: leadership, collaboration, calm control. No stock-looking handshakes, no glowing circuit boards.

Open question

One contradiction to resolve with the brand owner

The colour misuse page rules out gradients, but the manual's own section covers, ID cards and billboard all use a deep ink-to-blue gradient atmosphere. The workable reading is that the ban applies to colour application — flat fills for type, UI surfaces and the logo — while the gradient survives as a photographic background treatment. This system is built to that interpretation, and no gradient appears on any component. Worth getting confirmed in writing.

Extension log

Everything in this system that the manual does not cover, and the reasoning behind each call. Review this list with the brand owner — it is where the system is most likely to need adjusting.

AreaWhat the manual saysWhat was addedWhy
Neutral ramp Six colours, no unapproved colours Seven interpolated steps Hover, border and disabled states need intermediate values. Every step sits on a line between two approved colours, so no new hue enters.
Status colours Nothing Success, warning, error, info A form cannot report a validation error with navy and blue alone. Kept desaturated, restricted to product UI, and always paired with a written label. No tinted background fills — status is named, not washed.
Colour naming Two colours both named "Ink Black" Ink Black and Ink Navy Duplicate names cannot be referenced unambiguously in code or in conversation.
Type scale 144 / 48 / 18pt Thirteen-step web scale Print sizes don't map to screens directly. The ratios and case rules carry across; body stays at 18px exactly.
Spacing Nothing beyond logo clear space 4px base grid, eleven steps Without a shared scale, spacing drifts as soon as more than one person touches the code.
Radius Nothing stated Pill for controls, 8–12px for containers Read from the identity: the billboard CTA is a pill and the bug is a circle.
Elevation "Do not apply effects" (identity) Borders-first, four ink-tinted shadows Floating layers need to read as floating. Shadows are low-spread and tinted with Ink Black rather than grey.
Interaction states Nothing Hover, focus, active, disabled, loading, error Undefined states are where a brand silently falls apart in production.
Focus ring Nothing Surface-scoped: Blue Slate on light, Pale Sky on ink No single palette colour clears 3:1 on both surfaces.
Motion Nothing Three durations, two easings, reduced-motion handling Movement should confirm actions, matching the "structured" tone. Nothing bounces.
Layout Nothing 1280px container, 12 columns, five breakpoints The manual is built for fixed-size artboards; the web needs a responsive frame.

Not yet covered

Modals and drawers, toasts, pagination, breadcrumbs, tooltips, date pickers, empty states, skeleton loading, and the navigation header and footer. All are straightforward to add on the same tokens once the extensions above are signed off.
